# **App Name**: DalyDough

## Core Features:

- AI Market Regime Detection: Use AI to analyze live market data and classify the current market regime as Trending, Ranging, Volatile, or Dead.
- Adaptive D-Score Algorithm: Employ AI as a tool to dynamically adjust D-Score calculations based on market regime, influencing trade execution.
- D-Score Visualization: Display the real-time D-Score of currency pairs, incorporating trend alignment, volatility, and institutional data.
- Risk Dashboard: Visualize risk metrics, profit/loss, and trade history in an intuitive dashboard with night visibility.
- Institutional Data Integration: Pull data from FMP and CFTC APIs to feed into the scoring and market regime algorithms.

## Style Guidelines:

- Primary color: Dark indigo (#4B0082), to evoke a sense of professionalism and sophistication suitable for financial applications, especially in dark mode.
- Background color: Very dark indigo (#1A0033), near black but still carrying a tint of the primary color's hue.
- Accent color: Violet (#8A2BE2) to provide contrast and highlight key interactive elements.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text, ensuring legibility and a modern aesthetic.
- Code font: 'Source Code Pro' for displaying API keys or code snippets.
- Use minimalist, high-contrast icons to represent various data points and controls.
- Implement a grid-based layout with a collapsible sidebar for easy navigation and clear data presentation.
